# Формат / Format

## Что подменяется
Для каждого слота в паке лежит один текстурный ассет `T_<Слот>_Skin` (64×64, BGRA8, без mip) по пути `Dungeons/Content/Spicewood/Art/Characters/Player/Skins/<Папка>/`. Пак собирается `retoc to-zen --version UE5_6` из legacy-структуры (`.uasset` + изменённый `.uexp`) в `Dungeons-ZZZ_Skins_P.{utoc,ucas,pak}`. Оригинальные архивы игры не трогаются.

## Пиксели в `.uexp`
Пиксельные данные текстуры — 16 384 байта (64×64×4, порядок B,G,R,A) непосредственно перед завершающим блоком `int32 64, int32 64, int32 1`. Смещение начала считается от этого блока, а не от «магического» числа (ошибка на 4 байта = сдвиг на 1 px).

## Атлас
Игровой атлас — **не** раскладка Java. Конвертер берёт реальные треугольники и UV меша `SK_Player_Master` (608 вершин, 770 треугольников), группирует их в грани кубов частей тела (голова, тело, руки, ноги, слой шляпы) и для каждого текселя атласа выбирает соответствующий пиксель Java-скина, учитывая ось, отражение и slim (3 px) / classic (4 px) руки. Схема: `docs/img/layout_map.png`; сравнение своей и нативной раскладки: `ref_ours.png` / `ref_native.png`.
- Слой шляпы (0..16, 32..64) копируется 1:1 из Java.
- Иконка героя: 8×8 текселей в области (56..63, 20..27) — лицо + шляпа скина (проверено маркерным тестом: `docs/img/icon_marker_test.png`).
- Текселы, не принадлежащие ни одной грани куба, — игровые глаза/брови/рот (см. `EYES.md`).

## Меш
`tools/extract_from_game.py` читает из `SK_Player_Master.uexp` (UE5.6): индексы (u16, смещение 3871, 2310 значений), позиции (f32×3, смещение 8507, 608 вершин), UV (f16×2, смещение 20701, значения ×64 — в текселях). Данные проверяются на разумность; при несовпадении версии скрипт останавливается.
