# Гайд для друзей: свои скины в Minecraft Dungeons II

Только для себя, на своей копии игры (Steam). Игровые файлы не изменяются: добавляется один пак `Dungeons-ZZZ_Skins_P.*`, удалили — всё как было.

## Если вам прислали готовый пак (папка `pack\`)
1. Закройте игру. Steam → Minecraft Dungeons II → Управление → Просмотреть локальные файлы → `Dungeons\Content\Paks`.
2. Скопируйте туда три файла `Dungeons-ZZZ_Skins_P.pak`, `.ucas`, `.utoc` (рядом с `Dungeons-Windows.*`). Ничего не заменяйте.
3. Запустите игру. Пак работает только для той версии игры, на которой собран.
4. Откат: удалите эти три файла.

## Если хотите свои скины
1. Установите Python 3.10+ (python.org, галочка *Add python.exe to PATH*).
2. Скачайте репозиторий https://github.com/M1rs3m/dungeons2-skin-loader (Code → Download ZIP) и распакуйте.
3. `pip install pillow numpy`
4. Один раз: `python tools/extract_from_game.py --aes 0xВАШ_КЛЮЧ` (ключ AES вашей копии игры; в репозитории его нет).
5. Положите PNG в `skintool/skins/` (имя файла = слот, например `Pink.png`) и запустите `skintool\run.bat`: выберите скины, «Поставить». Или `python skintool/build.py`.
6. «Откатить» в окне или `skintool\restore.bat` — удаляет пак.

Замечания: выбранный слот заменяет героя этого цвета для всех ваших героев такого слота; глаза рисуются статично (режим `hide`); не запускайте установку при открытой игре.
